# Credit-Risk-Baseline
Predict probability of default for consumer loans to support underwriting decisions
## Data Source

This project uses Lending Club loan performance data.

Due to data size and governance considerations, raw data is not stored in this repository.

To reproduce results:
1. Download Lending Club `loan.csv` from Kaggle
2. Place file in Google Drive (or equivalent)
3. Update `DATA_PATH` in notebooks
